# AddressBook-systems
Implementation of AddressBook systems project in C

## Description
A menu-driven AddressBook application developed in C.
It allows users to add, search, edit, delete and list contacts.

## Features
- Add contact
- Search contact
- Edit contact
- Delete contact
- List all contacts
- Validate mobile number
- Validate email ID
- Prevent duplicate contacts
- File handling for data storage

## Technologies Used
- C Programming
- Structures
- File Handling
- Pointers
- String Handling

## How to Run

Compile:

gcc *.c -o addressBook

Run:

./addressBook
